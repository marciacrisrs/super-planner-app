# Design system reference

See [`docs/design-system.md`](./design-system.md) for the official **Super Planner** visual language.

The Compose implementation lives in `app/src/main/java/com/gpsdavida/app/ui/theme`.

The approved visual reference is the editorial Super Planner composition: warm cream canvas, dusty rose and terracotta accents, sage/blue-gray/lavender secondary tones, elegant serif typography, cursive Planner signature, compass motif and restrained organic illustrations.
