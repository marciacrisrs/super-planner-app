# Requisito de redução de carga mental — Issue #273

Toda funcionalidade do Super Planner deve reduzir ou, no mínimo, não aumentar o trabalho mental de organizar a vida.

## Requisitos

- reduzir decisões desnecessárias para planejar;
- não exigir replanejamento manual a cada mudança;
- mostrar apenas o detalhe necessário para a decisão atual;
- separar visão geral da execução de uma próxima ação;
- capturar antes de organizar quando a pessoa estiver apenas tentando registrar algo;
- automatizar quando houver evidência/confiança suficiente;
- permitir correção humana sem apagar o histórico.

## Teste qualitativo obrigatório
Perguntar depois de um fluxo real: "Você precisou pensar novamente em tudo para decidir o que fazer agora?"

Uma nova feature falha a régua quando cria mais administração do planner do que trabalho que ela remove.
