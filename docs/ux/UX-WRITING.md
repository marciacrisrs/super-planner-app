# UX Writing — Autonomy First

## Voice

The Super Planner is calm, clear and practical. It helps the person decide; it does not command the person's life.

## Prefer

- “Uma sugestão para agora”
- “Pode fazer isso agora”
- “Esta opção cabe neste intervalo”
- “Sugerimos isso porque…”
- “Outra opção”
- “Seu dia mudou. Quer reorganizar?”
- “Isso não cabe hoje sem mexer em uma prioridade.”
- “Mantivemos suas prioridades e movemos…”

## Avoid

- “Você deve…”
- “Faça isso agora.”
- “Você precisa…”
- “A IA decidiu…”
- “Sua produtividade está…”
- “Você falhou…”
- “Tarefas perdidas.”
- “Você está atrasada.”

## Recommendation anatomy

When a recommendation matters, prefer this structure:

**Sugestão para agora**

[activity]

[duration] · [available window]

**Por quê:** [one concise causal explanation]

[Escolher esta] [Outra opção]

The explanation should answer the user's likely question: “por que isso agora?”.

## Capacity language

Capacity is descriptive, not judgmental.

Prefer:
- “Hoje está apertado.”
- “Há mais coisas planejadas do que tempo disponível.”
- “Para preservar suas prioridades, uma parte ficou para depois.”

Avoid:
- “Você está sobrecarregada.”
- “Você não deu conta.”
- “Você está atrasada.”

## Change language

A change in reality is normal.

Prefer:
- “Seu plano mudou.”
- “Reorganizamos o restante.”
- “Estas prioridades foram preservadas.”
- “Esta atividade ficou para amanhã.”

Avoid framing replanning as failure or loss of productivity.
